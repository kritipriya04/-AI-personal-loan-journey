# AI-Powered Personal Loan Journey

A conceptual UX/UI project exploring how AI can make personal loan
applications simpler, clearer and more trustworthy.

## Project Goal

How might we help first-time borrowers understand, apply for, and
manage a personal loan with less confusion and uncertainty?

## Key Features

- Loan eligibility journey
- Loan options and EMI planning
- Personal details and financial information
- KYC and document submission
- Application review
- Application status tracking
- AI Loan Guide for contextual assistance

## UX Focus

- Simplicity
- Transparency
- Trust
- Explainability
- Human oversight

## Technology

- React
- TypeScript
- Tailwind CSS
- Vite


This is a conceptual portfolio prototype created for UX exploration.
It is not an official Piramal Finance product.
